# NETRA — Government-Feed Demo Script (target 2:30)

This script runs entirely against the 30 Government Sentinel grid cameras, no
own footage. Its purpose is to show NETRA operating honestly on the actual
infrastructure the committee will judge it against: overlays and detection on
cameras that support them, an explicit admission where plate legibility or
cross-camera corroboration is absent, and a generated report as the
close-out artefact. Every claim on this recording must be traceable to
`docs/high-level-design.md` §2 and `docs/feed-recon-findings.md` — no number
or capability is asserted here that was not measured.

## Report procedure

1. Navigate to `<<TUNNEL_URL>>/report` (or the console's Report page, which opens this same backend endpoint in a new tab).
2. Set the time range to the last 24 hours and leave the camera filter unset to cover the full grid, matching the URL:
   `<<TUNNEL_URL>>/api/report?hours=24`
   (add `&cameras=cam01,cam13,...` to scope it, or `&plate=GJ01AB1234` to scope to one vehicle, if the committee asks for a narrower cut).
3. The backend returns an HTML report in the new tab. Use the browser's Print → Save as PDF, with destination "Save as PDF" and background graphics on (so the table borders and status colours are preserved).
4. Name the saved file `netra-government-feed-report-YYYYMMDD.pdf`, using the date the report was generated (e.g. `netra-government-feed-report-20260907.pdf`).
5. What the committee should look at in the PDF:
   - The camera-condition summary (serviceable / plate-adequate / indoor / degraded counts) — confirms the 30-camera profile is unchanged from the HLD.
   - The detection and vehicle-count totals for the window — cross-checks against what was shown live on the Traffic page.
   - The scene-time-corroborated column — only cam13 rows should carry a corroborated timestamp; every other row should show stream time, and a report showing otherwise indicates a regression.
   - The plate-read column — expect it empty or near-empty for grid cameras other than the own-feed test source, consistent with the §2.4 measurement.
   - The audit trail excerpt at the foot of the report, showing which role generated it.

## What not to say

- Do not claim a plate was read on any Government grid camera other than in the context of the zero-result measurement itself.
- Do not present cam13's corroborated scene time as though it applies to any other camera on the grid.
- Do not claim a cross-camera journey exists in this sandbox; the intelligence page's empty banner is the honest result, not a bug to explain away.
- Do not claim facial recognition; NETRA has none.
- Do not describe the 6 degraded or 2 indoor cameras as "temporarily offline" or imply they will start working without hardware or positioning changes — the HLD attributes this to installed condition, not a software limitation NETRA can patch around.
